A Node 22 program, standard library only, that writes one short calm text to `/output/entry.txt`: on a warm night under a mosquito net, a grandmother fans a child with a palm-leaf fan, and the strokes slow until both of them are asleep. It checks the text against the bounty's gate (1 to 1,000 code points, not only white space) before writing, and writes the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
